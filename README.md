# EnergyDash Pro

EnergyDash Pro is an open-source Energy Management System (EMS) for residential and prosumer photovoltaic installations.

Built around Shelly Pro EM devices, it provides:

- Real-time power flow monitoring
- Historical energy analytics
- Automated PDF and Excel reporting
- Self-consumption and self-sufficiency metrics
- Grid import/export tracking
- Financial and ROI analysis
- Alerting and notifications
- Web-based configuration
- REST API integration
- PostgreSQL-backed data storage
- Mobile-friendly interface

## Technology Stack

- FastAPI
- PostgreSQL
- Dash / Plotly
- Python
- Nginx
- Systemd
- Open-Meteo
- Shelly Pro EM
