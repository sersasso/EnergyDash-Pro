# Contributing to EnergyDash Pro

First of all, thank you for considering contributing to EnergyDash Pro.

EnergyDash Pro is an open-source Energy Management System (EMS) focused on photovoltaic energy monitoring, reporting, analytics, and automation.

We welcome all forms of contributions, including:

- Bug reports
- Feature requests
- Documentation improvements
- UI/UX enhancements
- Security improvements
- Code contributions
- Testing and validation
- Translation efforts
